# Mac截图语音工具

一个轻量的 macOS 菜单栏工具，提供区域截图编辑、置顶贴图、长按语音输入和权限诊断。

## 功能特性

### 截图与编辑
- 全局快捷键触发区域截图：`⌘+Shift+S`
- 截图后打开浮动编辑器
- 支持画笔、矩形、圆形、箭头、文字标注
- 支持保存截图和钉到屏幕

### 语音输入
- 全局快捷键长按录音：`fn`
- 松开后调用小米 MiMo ASR 识别
- 识别结果优先自动粘贴到当前应用
- 自动粘贴失败时保留到剪贴板，并给出托盘提示

### 菜单栏常驻
- 主窗口可隐藏到菜单栏
- 托盘菜单支持截图、运行诊断、打开权限设置、退出
- 诊断会显示辅助功能、屏幕录制、API、配置文件和缓存路径状态

### 剪贴板历史
- 可选启用，仅记录文本内容
- 忽略空内容、重复内容、过长内容、图片和文件
- 可从菜单栏或快捷键打开历史列表
- 选择历史项后复制回剪贴板，可选自动粘贴

## 安装与启动

### 使用打包应用

```bash
./install_app.sh
```

也可以使用安装镜像：

```bash
open Mac截图语音工具.dmg
```

打开后将 `Mac截图语音工具.app` 拖到 `Applications`。

### 源码运行

```bash
./run.sh
```

或手动运行：

```bash
python3 -m venv venv
source venv/bin/activate
brew install portaudio
pip install -r requirements.txt
python3 main.py
```

## 权限设置

首次使用需要授予以下 macOS 权限：

- 屏幕录制：截图功能需要
- 麦克风：语音录音需要
- 辅助功能：全局快捷键拦截和自动粘贴需要
- 输入监控：全局快捷键监听需要

可从应用托盘菜单打开：

```text
权限设置 > 辅助功能
权限设置 > 输入监控
权限设置 > 屏幕录制
权限设置 > 麦克风
```

也可以手动打开：

```text
系统设置 > 隐私与安全
```

打包应用通常授权 `Mac截图语音工具.app`；源码运行时，macOS 可能要求授权 Terminal、iTerm 或 Python。

## API 配置

语音识别使用小米 MiMo ASR。API Key 可以在应用设置里配置，也可以用环境变量覆盖：

```bash
export MIMO_API_KEY="your_api_key_here"
```

获取 Key: https://platform.xiaomimimo.com/

## 使用方法

| 快捷键 | 功能 |
|--------|------|
| `⌘+Shift+S` | 区域截图 |
| `fn` | 长按录音，松开识别并输入 |
| `⌘+Shift+H` | 打开剪贴板历史 |

截图流程：

1. 按 `⌘+Shift+S`
2. 选择截图区域
3. 在浮动编辑器里标注、保存或钉到屏幕

语音输入流程：

1. 在目标应用中放好光标
2. 长按 `fn` 开始录音
3. 松开快捷键
4. 识别结果会自动粘贴；失败时可手动 `Cmd+V`

## 常见问题

### 快捷键不生效

在托盘菜单打开 `权限设置 > 辅助功能` 和 `权限设置 > 输入监控`，允许当前运行的应用。

### 截图失败

在托盘菜单打开 `权限设置 > 屏幕录制`，允许应用后重启应用。

### 语音输入没有自动粘贴

请确认辅助功能权限已允许。若自动粘贴失败，识别结果会保留到剪贴板，可手动按 `Cmd+V`。

### 看不到窗口

应用默认常驻菜单栏。点击菜单栏图标可显示或隐藏主窗口；托盘菜单里也有退出入口。
