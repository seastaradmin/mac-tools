Mac截图语音工具 - 启动说明

========================================

1. 首次启动

   打开终端，进入项目目录：
   cd /Users/ping/Desktop/mac-tools

   运行启动脚本：
   ./run.sh

   脚本会自动：
   - 创建 Python 虚拟环境
   - 安装依赖
   - 启动应用程序

2. API Key

   语音识别使用小米 MiMo ASR。

   推荐在应用内配置：
   - 打开主窗口
   - 点击设置按钮
   - 输入 MiMo API Key 并保存

   也可以在启动前设置环境变量：
   export MIMO_API_KEY="your_api_key_here"

3. 权限设置

   首次使用需要授予以下权限：
   - 屏幕录制权限（用于截图）
   - 麦克风权限（用于录音）
   - 辅助功能权限（用于全局快捷键和自动粘贴）

   可从托盘菜单打开：
   - 权限设置 > 辅助功能
   - 权限设置 > 屏幕录制
   - 权限设置 > 麦克风

   也可以手动进入：
   系统设置 > 隐私与安全

4. 快捷键

   ⌘+Shift+S: 区域截图
   ⌘+Shift+V: 长按录音，松开识别并输入

5. 功能说明

   截图：按快捷键后选择区域，自动进入浮动编辑器，可保存或钉到屏幕。
   语音输入：在目标应用放好光标，长按快捷键录音，松开后自动识别并粘贴。
   诊断：托盘菜单选择“运行诊断”，查看权限、API 和数据路径状态。

6. 故障排除

   如果遇到问题：
   - 先运行托盘菜单里的“运行诊断”
   - 检查权限设置是否完整
   - 检查网络和 MiMo API Key
   - 查看终端输出的错误信息

7. 更新依赖

   source venv/bin/activate
   pip install -r requirements.txt --upgrade

8. 退出程序

   关闭窗口只会隐藏应用。请从菜单栏托盘菜单选择“退出”。
